ÜBERGABE: Mailversand der Website auf Microsoft Graph umstellen
================================================================

Diese Datei gehört zu: graph-mailversand.bundle
Repo: CalvinLinke/Plasma-1   |   Branch: graph-mailversand   |   Basis: main

WAS IST DRIN (3 Commits, fertig & lokal getestet)
-------------------------------------------------
1. Mailversand über Microsoft Graph statt SMTP
   - neuer Helper lib/graph-mail.ts (Graph sendMail, Client-Credentials/App-only)
   - app/api/angebot/route.ts nutzt sendMailViaGraph statt nodemailer
2. Kontaktformular ebenfalls auf Graph + nodemailer entfernt
   - app/api/kontakt/route.ts auf Graph umgestellt
   - nodemailer raus aus package.json + Lockfile
   - .env.local.example dokumentiert die MS_*-Variablen
3. Doku: docs/SMTP-Uebergabe-Robert.md ersetzt durch docs/Mailversand-Graph.md

Hintergrund: box@plasma-energie.de ist ein freigegebenes Postfach (kein Login) und
der Tenant erzwingt MFA -> SMTP unmöglich. Eine Entra-App sendet jetzt per Graph als
box@. Vercel-Env-Variablen (MS_TENANT_ID/MS_CLIENT_ID/MS_CLIENT_SECRET/MS_SENDER_UPN)
sind bereits gesetzt. Die App ist per Application Access Policy auf box@ eingegrenzt.
Lokal getestet: /api/kontakt und /api/angebot -> HTTP 200, Mails kommen in box@ an.
